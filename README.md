# 工位伴侣

一个趴在桌面右下角的 Q 版小助手，帮你盯着下班倒计时，顺便提醒你起身、吃饭、写周报。

Windows 桌面挂件，Python + PySide6，单文件 exe，不装环境直接跑。

![角色](assets/char/14_cheek.png)

## 能做什么

**下班倒计时**
卡片上半是一个大号倒计时，下方细条显示今天的进度；临近下班变橙，过了下班点转成加班计时。

**会动的角色**
她趴在卡片上沿，可以点、可以摸、可以拖：

| 操作 | 反应 |
|---|---|
| 点一下 | 随机表情（笑 / 眨眼 / 蹦） |
| 连点 5 下 | 生气 |
| 按住 2 秒 | 被拎起来，放下时随机情绪 |
| 鼠标碰到 | 摸头反应，先一激灵再害羞 |
| 拖动窗口 | 按拖动速度播放踉跄 / 扑地，松手摔倒再爬起来 |
| 中午饭点 | 开锅 → 盛饭 → 捧碗 → 猛吃 → 吃撑，循环播放 |

**久坐提醒**
工作时段计时，满 45 分钟弹窗提醒起身；午休、上班前、下班后自动暂停。卡片上有一个「起来了」按钮，点一下直接重置。

**周报 / 月报**
本周最后一个工作日 17:40 提醒写周报；如果这周正好是本月最后一个工作周，改成提醒月报。点「写过了」当天不再打扰。

**天气**
右上角显示当前天气图标和温度，30 分钟刷新一次，可在设置里指定城市。

**自定义主题**
内置角色叫「大肥鱼」，只读。可以新建主题，逐个槽位上传自己的图 —— 28 个动作槽位分 6 类，没上传的自动回落到默认图。上传的图会自动缩放居中，检测到白底自动抠掉。

## 怎么用

1. 下载 `DeskMate.exe`，双击运行
2. 首次运行在右下角出现卡片，右键图标或卡片进设置
3. 设置里填上下班时间、工作日、久坐间隔、天气城市

### 便携模式

把 `DeskMate.exe` 和一个空的 `portable.txt` 放在同一个文件夹里，配置和自定义主题就会写到旁边的 `DeskMate-data\`，整个文件夹拷到别的电脑可以直接用。

不加 `portable.txt` 则存在 `%APPDATA%\DeskMate`。

### 系统要求

- Windows 10 1809 以上 / Windows 11
- 64 位

运行库已打包进 exe，不需要额外安装。

## 开发

```bash
python -m venv .venv
.venv\Scripts\pip install PySide6 pyinstaller
.venv\Scripts\python main.py     # 直接跑
build.bat                        # 打包成 dist\DeskMate.exe
```

### 代码结构

| 文件 | 职责 |
|---|---|
| `main.py` | 入口、托盘、菜单、事件分发 |
| `engine.py` | 时间计算、阶段判定、久坐与提醒事件 |
| `card.py` | 卡片窗口、绘制、鼠标交互 |
| `fish.py` | 角色的状态机、动画、粒子 |
| `char_theme.py` | 主题仓库、28 个槽位定义、帧集回落 |
| `image_proc.py` | 上传图片的缩放与抠图流水线 |
| `theme_ui.py` | 主题管理器与槽位编辑器 |
| `settings.py` | 设置面板 |
| `weather.py` | 天气请求与矢量图标 |
| `update.py` | 检查更新 |
| `theme.py` | 配色、字体、QSS |
| `toast.py` | 提醒弹窗 |

### 发版

1. 改三处版本号：`config.py` 的 `APP_VERSION`、`version_info.txt`、根目录 `VERSION`
2. 在 `CHANGELOG.md` 顶部加一段这次的更新内容
3. `build.bat` 打包（会先关掉正在运行的实例，打完自动复核版本并生成 `SHA256SUMS`）
4. 在 GitHub 建一个 release（tag 用 `v版本号`），**把 `dist/DeskMate.exe` 作为附件传上去**，文件名必须是 `DeskMate.exe`
5. 提交并推送（`SHA256SUMS` 要一起提交）

检查更新的下载地址是 `releases/latest/download/DeskMate.exe`，所以只要最新那个 release 里有这个附件就能用。
第 4 步忘了，用户会看到新版本号却下载不到包。

客户端下载完会拿 `SHA256SUMS` 校验，对不上就放弃更新 —— 所以 3 和 5 的顺序不能颠倒：
**先打包生成 SHA256SUMS，再提交，再传 release**，保证三者的哈希是同一份文件。
