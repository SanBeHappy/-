# 工位伴侣

一个趴在桌面右下角的 Q 版小助手：帮你盯着下班倒计时，顺便提醒你起身、喝水、写周报，到点还能替你关电脑。

Windows 桌面挂件，Python + PySide6 写成，解压即用，不需要装环境。

![角色](assets/char/14_cheek.png)

## 能做什么

**下班倒计时**
卡片上半是大号倒计时，下方细条显示今天的进度；临近下班变橙，过了下班点自动转成加班计时。可设置提前多少分钟先提醒一次。

**会动的角色**
她趴在卡片上沿，可以点、可以摸、可以拖：

| 操作 | 反应 |
|---|---|
| 点一下 | 随机表情（笑 / 眨眼 / 蹦） |
| 连点 5 下 | 生气 |
| 按住 2 秒 | 被拎起来，放下时随机情绪 |
| 鼠标碰到 | 摸头反应，先一激灵再害羞 |
| 拖动窗口 | 按拖动速度播放踉跄 / 扑地，松手摔倒再爬起来 |
| 中午饭点 | 开锅 → 盛饭 → 捧碗 → 猛吃 → 吃撑，循环播放 |

**久坐提醒**
工作时段计时，满 45 分钟提醒起身；午休、上班前、下班后自动暂停。卡片上的「起来了」一点就重新计时，也可以让提醒暂停 30 分钟。

**喝水提醒**
卡片右侧有个水杯，水量按离上次喝水的时间涨，分五档素材。到点弹常驻提醒窗，点「喝了」记一杯并重新计时；菜单里有「喝水重置」，不计杯数。杯数每天自动归零。

**周报 / 月报**
本周最后一个工作日 17:40 提醒写周报，如果这周正好是本月最后一个工作周，改成提醒月报。提醒窗里有「打开飞书」，点一下直接唤起桌面版飞书去写；点「写过了」当天不再打扰。

**自动关机**（默认关闭）
设置里可以选星期 + 时间，到点自动关机。关机前 5 分钟弹常驻提醒，不想关就点「今晚不关」，当天不再执行。晚于设定时间超过 1 分钟不补关，避免电脑睡眠唤醒后突然关机。

**下班收尾**
到下班时间点自动：关掉微信 → 按 Win+D 回到桌面 → 关闭显示器。微信先正常退出，关不掉再强制结束；自动关机的那天不执行，避免和关机流程打架。

**天气**
右上角显示当前天气图标和温度，半小时刷新一次，可在设置里指定城市。

**自定义主题**
内置角色叫「大肥鱼」，只读。可以新建主题，逐个槽位上传自己的图 —— 28 个动作槽位分 6 类，没上传的自动回落到默认图。图片会自动缩放居中，检测到白底自动抠掉。

**其它**
开机自启、便携模式、自动更新（带 SHA256 校验）、托盘菜单、窗口位置记忆。

## 下载与安装

1. 到 [Releases](https://github.com/SanBeHappy/Workhorse/releases/latest) 下载 `DeskMate.zip`
2. 解压到任意目录（比如 `D:\Tools\DeskMate`）
3. 双击里面的 `DeskMate\DeskMate.exe`

> 必须整个 `DeskMate` 文件夹一起用，不能只拷 exe —— 依赖都在旁边的 `_internal\` 里。

首次运行后卡片出现在屏幕右下角，托盘里会有图标；右键图标或用卡片上的 `⋯` 进设置，填上下班时间、工作日、久坐与喝水间隔、天气城市。

### 数据存在哪

默认在 `%APPDATA%\DeskMate`（配置、自定义主题、错误日志）。

**便携模式**：把空的 `portable.txt` 放在 `DeskMate.exe` 旁边，配置就写到同级的 `DeskMate-data\`，整个文件夹拷到别的电脑可以直接用。

### 系统要求

- Windows 10 1809 及以上 / Windows 11
- 64 位

运行库随目录一起打包，不需要额外安装。

## 为什么是目录而不是单文件

早期版本打成单文件 exe，每次启动都要往 `%TEMP%` 解压一份 `_MEI*` 临时目录，跑久了会攒出一堆垃圾，启动也慢。现在改成目录模式（`--onedir`），启动直接读目录，不留临时文件。

代价是发布包变成 `DeskMate.zip`（解压出一个目录），自动更新也从「替换 exe」变成「换目录」：下载 → 校验 → 解压 → 退出 → 旧目录改名 `DeskMate.old`、新目录就位、拉起新版，下次启动自动清掉 `.old`。

> 从 1.0.21 及更早的单文件版升上来，需要手动下载解压替换一次；之后都能自动更新。

## 开发

```bash
python -m venv .venv
.venv\Scripts\pip install PySide6 pyinstaller
.venv\Scripts\python main.py     # 直接跑
build.bat                        # 打包成 dist\DeskMate\，并生成 dist\DeskMate.zip
```

`check_build.py` 会核对 `dist\DeskMate\DeskMate.exe` 的文件版本是否等于 `config.APP_VERSION`，顺便压 zip、写 `SHA256SUMS`。打包前记得先关掉正在运行的实例，否则文件被占用会打出旧包。

### 代码结构

| 文件 | 职责 |
|---|---|
| `main.py` | 入口、托盘、菜单、事件分发 |
| `engine.py` | 时间计算、阶段判定、久坐 / 喝水 / 周报事件 |
| `card.py` | 卡片窗口、绘制、鼠标交互 |
| `fish.py` | 角色的状态机、动画、粒子 |
| `char_theme.py` | 主题仓库、28 个槽位定义、帧集回落 |
| `image_proc.py` | 上传图片的缩放与抠图流水线 |
| `theme_ui.py` | 主题管理器、槽位编辑器、更新弹窗 |
| `settings.py` | 设置面板 |
| `weather.py` | 天气请求与矢量图标 |
| `shutdown.py` | 自动关机：判定、5 分钟提醒、执行 `shutdown /s` |
| `feishu.py` | 一键打开飞书（协议优先，退回安装目录） |
| `toast.py` | 提醒弹窗与落点计算 |
| `update.py` | 检查更新、下载 zip、换目录 |
| `theme.py` | 配色、字体、QSS |
| `check_build.py` | 打包后自检 + 压 zip + 生成 SHA256SUMS |

### 发版

1. 改三处版本号：`config.py` 的 `APP_VERSION`、`version_info.txt`、根目录 `VERSION`
2. 在 `CHANGELOG.md` 顶部加一段这次的更新内容
3. `build.bat` 打包（会先关掉运行中的实例，打完复核版本、压出 `dist\DeskMate.zip` 并写 `SHA256SUMS`）
4. 在 GitHub 建 release（tag 用 `v版本号`），**把 `dist/DeskMate.zip` 作为附件传上去**，文件名必须是 `DeskMate.zip`
5. 提交并推送（`SHA256SUMS` 要一起提交）

客户端更新地址是 `releases/latest/download/DeskMate.zip`，下载完拿 `SHA256SUMS` 校验，对不上就放弃更新 —— 所以 3 和 5 的顺序不能颠倒：**先打包生成 SHA256SUMS，再提交，再传 release**。
